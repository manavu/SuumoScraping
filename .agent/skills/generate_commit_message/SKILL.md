---
name: generate_commit_message
description: ステージングされた変更内容からコミットメッセージを生成し、コミットを行います。
---

# 手順

1. **変更の確認**
   - 以下のコマンドを実行し、ステージングされたファイルがあるか確認してください。
     ```bash
     git diff --cached --name-only
     ```
   - 出力がない場合:
     - ユーザーに「ステージングされた変更がありません。`git add` してから再度実行してください」と伝えて終了します。

2. **変更内容の取得**
   - 以下のコマンドで詳細な変更内容を取得します。
     ```bash
     git diff --cached
     ```

3. **メッセージの生成**
   - 取得した差分に基づき、以下のフォーマットでコミットメッセージを作成してください（**原則日本語**）。
     ```
     <type>(<scope>): <subject>

     <body>
     ```
   - **Type一覧**:
     - `feat`: 新機能
     - `fix`: バグ修正
     - `docs`: ドキュメントのみの変更
     - `style`: コードの動作に影響しない変更（スペース、フォーマットなど）
     - `refactor`: バグ修正も機能追加も行わないコード変更
     - `perf`: パフォーマンスを向上させる変更
     - `test`: テストの追加・修正
     - `chore`: ビルドプロセスやツールの変更
   - **要件**:
     - `subject` は50文字以内で簡潔に。
     - `body` は変更の理由や詳細を記述（必要な場合）。

4. **ユーザー確認**
   - 生成したメッセージをユーザーに提示し、「このメッセージでコミットしますか？」と尋ねます (`notify_user`)。
     - **重要**: ここで勝手に `git commit` を実行しないでください。必ずユーザーの承認を得てください。

5. **コミットの実行**
   - ユーザーが承認した場合:
     - 以下のコマンドを実行します。
       ```bash
       git commit -m "<generated_message>"
       ```
   - ユーザーがメッセージの修正を求めた場合:
     - 指示に従ってメッセージを修正し、再度確認を求めます。
