# SuumoScraping - AI Agent Guideline

## 📌 概要・ドキュメントインデックス
このプロジェクトは、Suumoから物件情報をスクレイピングして管理する ASP.NET Core アプリケーションです。
- **基本技術・ビルド・環境構築手順**: [README.md](README.md) を最優先で参照してください。

---

## 🛡️ AIエージェントが厳守すべき「5つの掟」

本プロジェクトでコードの追加・変更を行うAIエージェントは、以下のコアルールを無条件で厳守してください。

1. **DDD（ドメイン駆動設計）の順守**
   - `Domain/`: 外部技術に依存しないビジネスルール（DTO・カスタム例外・抽象インターフェース定義）。
   - `UseCases/`: 各ビジネスロジックをカプセル化したアプリケーション層。
   - `Infrastructure/`: `HttpClient` 通信（Fetcher）、`HtmlAgilityPack` パース（Parser）、`Gateway` などの外部インフラ実装。
   - プレゼンテーション層（Controllers）やバッチは、直接DBコンテキスト等に依存せず `UseCases` を経由すること。

2. **完全非同期処理（async/await）の徹底**
   - データベースアクセス、ネットワークI/Oを伴う処理は、すべて `async/await` で非同期化してください。
   - `.Result` や `.Wait()` による同期ブロッキングは**厳禁**です。

3. **StyleCop警告「0件」の維持**
   - 静的コード解析 `StyleCop.Analyzers` が導入されています。ビルド時に警告が 1 件も出ない状態を維持してください。

4. **CSharpierによる整形**
   - コードを変更した後は、必ず `dotnet csharpier format .` を実行し、自動整形を適用してください（StyleCopとの競合を自動回避します）。

5. **Dockerコンテナ内でのコマンド実行**
   - コマンド実行（ビルド・テスト・整形等）は必ず Docker コンテナ内で実行してください。
   - ※ `docker` で始まるコマンドは承認プロンプトなしで即時実行可能です。
